# 06 · Simple displacement

- **Demo scene:** `06_Simple-Displacement.unity`

## Notes

UV displacement: the screen UV is offset by a texture value before sampling the frame. Any texture (here a red/green noise) can act as the displacement guide.

## Controls

Tab / 1-9: switch effect variant · 0: effect off · Space: pause the animated parameter

## Files

- **Shaders/**: `SimpleDisplacement.shader`
- **Materials/**: `M_SimpleDisplacement.mat`
