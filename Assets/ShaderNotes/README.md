# Shader notes (Built-in Render Pipeline)

Personal notes and experiments on shaders and image effects for Unity's Built-in Render Pipeline,
one folder and one demo scene per topic.

- Open `Assets/ShaderNotes/_Common/Scenes/00_Menu.unity` and press Play to browse all demos, or open any
  `NN_*/NN_*.unity` directly. Inside a demo: **N / B** next / previous, **M** menu, **H** hide the info panel.
- Each folder has a `README.md` with notes, the files and implementation notes.
- Third-party licence notice: `LICENSE_ThirdParty.txt`.
