# 31 · Radial blur

- **Demo scene:** `31_Radial-Blur.unity`

## Notes

The frame is sampled several times along the direction to a centre point with decreasing scale and averaged. _Radius keeps the centre sharp.

## Controls

Tab / 1-9: switch effect variant · 0: effect off · Space: pause the animated parameter

## Files

- **Shaders/**: `RadialBlur.shader`
- **Materials/**: `M_RadialBlur.mat`
