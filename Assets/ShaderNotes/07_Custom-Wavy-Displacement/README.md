# 07 · Custom wavy displacement

- **Demo scene:** `07_Custom-Wavy-Displacement.unity`

## Notes

A procedural displacement guide: a sine of uv.y is turned into alternating red/green values that push the image left and right.

## Controls

Tab / 1-9: switch effect variant · 0: effect off · Space: pause the animated parameter

## Files

- **Shaders/**: `CustomWaveyDisplacement.shader`
- **Materials/**: `M_CustomWavyDisplacement.mat`
